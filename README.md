# אפליקציית ניהול קבוצה ⚽

אפליקציה לניהול קבוצת כדורגל — צד צוות וצד שחקנים. עברית מלאה, מותאמת לטלפון, ניתנת להתקנה על מסך הבית.

## מה יש בפנים
- **צוות:** לוח בקרה עם התראות, סגל עם תמונות, סגל למשחק, הרכב על מגרש, רישום משחק חי (שערים, בישולים, חילופים, כרטיסים), ציונים ושחקן המשחק, לו״ז עם אישורי הגעה ונוכחות, ציוד ואחזקה, מידות מדים, כספים ומשכורות, מנהל טכני (משימות, צ׳קליסט יום משחק, אישורים רפואיים, סקאוטינג, יומן).
- **שחקנים:** אישור הגעה, לו״ז, הרכב שפורסם, סטטיסטיקה וציונים אישיים, טבלאות העונה.
- **וואטסאפ:** שליחת סגל, הרכב, תזכורת למשחק ולו״ז שבועי.

## אבטחה
- כניסה עם קוד: קוד קבוצה לשחקנים, קוד צוות להנהלה. הקודים נשמרים בשרת בלבד.
- שחקנים לא מקבלים מהשרת משכורות, כספים, הערות צוות וסקאוטינג.
- כל הסודות (חיבור למסד הנתונים, מפתחות) נמצאים במשתני סביבה ב-Vercel — לא בקוד.

## הרצה מקומית
```
npm install
npm run dev
```
במצב מקומי (בלי שרת) הנתונים נשמרים בדפדפן בלבד. קוד צוות: 1234.

## הגדרת שרת (Vercel + MongoDB)
משתני סביבה נדרשים: `MONGODB_URI`, `MONGODB_DB`, `AUTH_SECRET`, `INITIAL_MANAGER_PIN`, `INITIAL_TEAM_CODE`.
